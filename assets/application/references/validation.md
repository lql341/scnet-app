# Compatibility evidence

English | [中文](validation_CN.md)

Status: **unverified**. Generated scaffolding is not a compatibility report.

Record source revision and license; actual compute-node CPU/DCU architecture,
OS/glibc, driver/DTK, modules, compiler/framework, dtype and launch configuration.
Keep private job/node/account/path references in a separate private run record.

For each completed check, report the input/reference, numeric tolerance or
functional criterion, observed result, exit code, confirmed scheduler state,
device used, resource budget and evidence location. Do not turn installation,
import, compilation or enumeration alone into an application-support claim.

Begin with one node and one DCU where applicable. Measure scaling separately,
after correctness; record memory use, execution time and unverified boundaries.
